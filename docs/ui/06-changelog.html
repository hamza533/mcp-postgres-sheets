v1.0.0

— Production General Availability
Latest PyPI: v1.0.0 Release Notes open_in_new
event February 24, 2025 • Git Commit 9e2a7b8

First stable production release with multi-client support, strict SQL AST validation, and production-tested security hardening. This release delivers complete end-to-end telemetry and granular capability declarations compatible with Claude Code, Cursor, and custom agent toolsets.

verified_user Integrity Checksum
sha256:7f92023cb608e92f256a422...
Added New tools & capabilities
  • add_circle Full Google Sheets v4 integration with sheets_read_range and sheets_find_rows for structured range extraction.
  • add_circle Remote HTTP transport mode with RFC 6750 Bearer token support and strict OAuth 2.0 JWT scope checking for multi-tenant deployments.
  • add_circle Dedicated SQL AST parser actively rejecting multi-statements, DDL queries (ALTER, DROP), and dangerous Postgres internal admin routines.
  • add_circle Interactive client configuration presets targeting Cursor IDE, Claude Code, and ChatGPT Custom Actions.
Changed Behavioral & default modifications
  • sync_alt READ_ONLY is now strictly enforced to true by default; mutating tools fail registration unless explicitly flagged READ_ONLY=false.
  • sync_alt Default query execution timeout reduced from 30s to 15s to prevent synchronous AI agent socket starvation.
Security Hardening & CVE protections
shield Automated benchmark suite with 40 SQL injection and misuse vectors integrated into continuous integration on every branch and PR.
shield Resolved edge case where deeply nested subquery aliases could slip through table schema allow-lists during dialect transpilations.

v0.9.0

— Google Sheets Support & Idempotency
Breaking Changes GitHub Release open_in_new
event January 18, 2025 • Git Commit 5b4e10c

Introduced initial Google Sheets integration and structured idempotency keys to protect stateful workbooks against LLM retry loops.

warning
Breaking Change

Environment variable SHEET_IDS renamed to ALLOWED_SHEET_IDS to standardize security allow-list naming conventions across PostgreSQL and Google Workspace connectors.

Added Idempotent write handlers
  • add_circle Write tools sheets_append_rows and sheets_update_range requiring a client-supplied UUID idempotency_key to prevent duplicate entries.
  • add_circle Structured audit logging to standard out (stdout) with sub-millisecond execution timing and sanitized query strings.
