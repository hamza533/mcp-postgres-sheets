Server Configuration

System Env

All server behavior is configured via environment variables. Configure connection strings, safety boundaries, and transport modes for robust enterprise deployment.

Local Mode (stdio)

For single-user local contexts including Claude Desktop, Cursor workspace integration, and local shell sessions.

terminal TRANSPORT=stdio
  • check_circle Runs cleanly over standard input/output streams
  • check_circle Inherits credentials directly from parent process environment
  • check_circle Zero network surface area or ingress risk
Latency overhead < 0.2ms IPC
Enterprise Cluster JWT Bearer OAuth

Remote Mode (HTTP + SSE)

For centralized enterprise gateways, shared microservice runtimes, and ChatGPT custom GPT remote actions.

cloud_sync TRANSPORT=http
  • verified_user Exposes hardened HTTPS + SSE streaming endpoints
  • verified_user Validates Bearer tokens against OIDC issuer JWKS
  • verified_user Supports edge rate limiting and audit logging streams
Default Listener 0.0.0.0:8080
security
Security Requirement Strict

Never hardcode database passwords, connection strings, or service account JSON inside static client configuration files (such as claude_desktop_config.json). Use your OS keychain or inject environment variables dynamically via wrapper scripts or vault managers (e.g. AWS Secrets Manager, 1Password CLI, or HashiCorp Vault).

Production .env File Example

# Recommended Production Baseline
DATABASE_URL="postgresql://pg_mcp_app:secure_vault_pw@db.prod.internal:5432/analytics?sslmode=verify-full"
ALLOWED_SCHEMAS="public,reporting"
ALLOWED_TABLES="dim_users,fact_orders,monthly_kpis"
READ_ONLY=true
MAX_ROWS=500
QUERY_TIMEOUT_MS=8000
TRANSPORT="http"
HTTP_PORT=8080
OAUTH_ISSUER="https://auth.internal.corp"
OAUTH_AUDIENCE="mcp-pg-sheets"
REDACT_ARGS=true
RATE_LIMIT_PER_MIN=120
