sheets_update_range

write sheets:write
shield Disabled when READ_ONLY=true · Requires WRITE OAuth scope

Updates specific cell coordinates. Requires explicit WRITE scope and non-empty idempotency token.

Parameters
Field Type Requirement Description
sheet_id string required The target spreadsheet ID.
range string required A1 coordinate range to overwrite, e.g. 'Q4_Pipeline!B2'.
values array[] required 2D array matching the target range dimensions.
idempotency_key string required UUID v4 preventing replay of cell alterations.
save Overwrite Mutation
