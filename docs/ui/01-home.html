Architecture Guarantee

Engineered for absolute database integrity

Traditional tool implementations give models unmonitored SQL shells. PG Sheets MCP enforces strict constraints before queries touch your socket.

lock_reset

Read-only by default

Enforces Postgres read-only transaction mode and scopes at session initialization. Write tools and sheet mutations are omitted entirely unless explicitly toggled in configuration.

SET TRANSACTION READ ONLY verified
account_tree

Layered SQL safety

Full AST parsing evaluates statement trees before execution, allowing strictly single-statement SELECT queries. Blocks compound statements, DDL alterations, mutations, and sleep-injection payloads.

Deterministic AST Validation check_circle
vpn_key

OAuth scopes for remote use

Scoped authorization architecture for HTTP daemon mode. Distribute granular, signed bearer tokens: db:read, sheets:read, and an explicitly gated sheets:write.

RFC 6749 Scopes Compatible
receipt_long
