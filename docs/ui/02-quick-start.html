Quick Start Guide

Set up PG Sheets MCP and connect it to your favorite AI assistant with hardened read isolation in under five minutes.

Protocol Compatibility MCP Spec v2024.11
Default Security Tier verified_user Read-Only Enforced
Total Runtime Tools 8 Tools Registered
1

Create a read-only database role

Best practice dictates creating an isolated PostgreSQL user with strict read-only permissions, query cancellation timeouts, and schema visibility fences. This guarantees the AI agent cannot alter table state even if instructed maliciously.

terminal postgresql-init.sql 
-- Create read-only role and grant SELECT
CREATE ROLE mcp_readonly WITH LOGIN PASSWORD 'your_secure_password';
GRANT CONNECT ON DATABASE production TO mcp_readonly;
GRANT USAGE ON SCHEMA public TO mcp_readonly;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO mcp_readonly;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT ON TABLES TO mcp_readonly;
2

Share Google Sheet with the service account

Download your Google Cloud IAM service account JSON credentials and grant Viewer access to your specific spreadsheet IDs directly through the native Google Drive sharing modal.

info
Security Principle of Least Privilege

Never give Editor permissions to the service account unless you explicitly intend to activate mutation tools and set strict target sheet constraints via ALLOWED_SHEET_IDS.

code terminal.sh 
export GOOGLE_SERVICE_ACCOUNT_JSON="$(cat ./credentials/gcp-sa.json)"
export ALLOWED_SHEET_IDS="1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms"
3

Add the server to your AI client

Model Context Protocol integrates directly into desktop clients, IDE extensions, and cloud agent endpoints. Select your environment below for the targeted configuration snippet:

data_object claude_desktop_config.json 
{
  "mcpServers": {
    "pg-sheets": {
      "command": "uvx",
      "args": ["mcp-postgres-sheets"],
      "env": {
        "DATABASE_URL": "postgresql://mcp_readonly:password@db.internal:5432/production?sslmode=require",
        "ALLOWED_SCHEMAS": "public,analytics",
        "GOOGLE_SERVICE_ACCOUNT_JSON": "/path/to/sa-key.json",
        "READ_ONLY": "true"
      }
    }
  }
}

Locate this file at ~/Library/Application Support/Claude/claude_desktop_config.json on macOS or %APPDATA%\Claude\claude_desktop_config.json on Windows.

Claude Code CLI Registration

Execute the direct tool registration command via terminal within your workspace repository:

claude mcp add pg-sheets uvx mcp-postgres-sheets --env READ_ONLY=true
Cursor MCP Integration

Navigate to Cursor Settings > Features > MCP and add a new custom command with Type: command and Path: uvx mcp-postgres-sheets.

Remote SSE / HTTP Transport

For cloud agents and GPT Custom Actions, run in server daemon mode exposing the Model Context Protocol Server-Sent Events endpoint:

uvx mcp-postgres-sheets --transport sse --port 8080 --bearer-token secret_token
